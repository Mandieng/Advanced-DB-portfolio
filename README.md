# Advanced Database Systems Portfolio

A collection of database-design and implementation portfolios for the MIT 8103 Advanced Database Systems course.

## Portfolio 1: Ride-hailing and logistics

The first portfolio models a service that handles passenger rides and local deliveries, including customers, drivers, locations, trips, status history and payment attempts.

- [Portfolio overview and run instructions](portfolio-1-database-design/README.md)
- [Case study, relational design and business rules](portfolio-1-database-design/Mandieng_RideHailing_P1_Design.md)
- [ER diagram](portfolio-1-database-design/Mandieng_RideHailing_P1_ERDiagram.md)
- [Normalisation to 3NF](portfolio-1-database-design/Mandieng_RideHailing_P1_Normalisation.md)
- [PostgreSQL schema](portfolio-1-database-design/Mandieng_RideHailing_P1_Schema.sql)
- [Operational query examples](portfolio-1-database-design/Mandieng_RideHailing_P1_Queries.sql)
